Hidden Whys Studio — Privacy Policy

Effective date: 2026-10-25

Hidden Whys Studio ("the tool") is a private production tool that runs on a single computer owned by one operator, who runs two YouTube channels with it:

  • Hidden Whys (@HiddenWhys) — English Shorts that explain the hidden reasons behind strange sights.
  • 대망의 1위 (@대망의1위) — Korean Shorts that rank five clips on one theme.

The tool helps that one operator choose short video clips, edit them into Shorts (narrated explainers for Hidden Whys; top-five rankings with captions and sound effects for 대망의 1위) and publish the finished Shorts to the operator's own channels. The tool has no public users, no sign-up, and no server of its own.

YouTube API Services

The tool uses YouTube API Services. By using its YouTube features you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What the tool accesses

With the operator's authorization (OAuth), for the operator's own channels only. Each channel is connected separately with its own authorization, and each channel's data is used only for that channel's records:

  • Channel ID, title and subscriber count.
  • The channel's recent uploads (video ID, title, privacy status, scheduled publish time), to link videos the operator uploaded in YouTube Studio to the matching production records.
  • Statistics (views, likes, comments) and YouTube Analytics reports (for example engaged views, average view percentage, subscribers gained) for the channel's own videos.
  • Uploading the operator's own finished videos, and changing their privacy status (for example making a video private when a creator asks us to take it down).
  • Posting one comment from the channel's own account on each of its published videos (a question for viewers, or the list of credited original creators).
  • Comments on the channel's own videos, including replies and comments held for review or as likely spam (comment ID, author display name, text up to 300 characters, time), read every few hours only to notice takedown requests from original creators. Matching comments are shown to the operator and deleted from the local database within 30 days.

Without authorization, using an API key:

  • Public metadata of videos returned by YouTube search (search.list, videos.list): title, channel name, thumbnail URL, view count, description, duration and publish date. This is used only to suggest candidate clips to the operator.

The tool does not access any other user's account, subscriptions, or private data, or comments on other channels' videos.

How the data is stored

  • Everything is stored locally in a database file on the operator's computer. There is no remote server operated by us.
  • OAuth tokens are stored in that local database and are used only to call the APIs listed above.
  • Public video metadata from search is kept for at most 30 days. After that it is deleted or replaced with our own records, as required by the YouTube API Services Developer Policies.
  • Statistics older than 30 days are deleted; the latest values, including the subscriber count, are refreshed regularly. Channel analytics are kept while the channel remains connected and are deleted 30 days after the connection is removed.
  • Local database backups are kept on the same computer and rotated.

How the data is used and shared

  • To suggest and score candidate clips, show production status, schedule uploads, and measure how published Shorts perform so that future topics can be chosen better.
  • When the operator enables the Claude API, the titles, descriptions and thumbnail images of candidate videos, frames and transcripts of the clips the operator chose, and the scripts and captions we write are sent to Anthropic's Claude API for analysis and scoring. Anthropic processes this data under its commercial terms. No YouTube data is sold or shared with anyone else.

Revoking access and deleting data

  • The operator can disconnect each channel in the tool (Settings → YouTube channel connection). This deletes that channel's stored tokens and revokes them with Google.
  • Access can also be revoked at any time from the Google security settings page: https://security.google.com/settings/security/permissions.
  • To have data deleted, contact us at the address below; deletion is done within 7 days.
